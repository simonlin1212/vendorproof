<h1 align="center">VendorProof</h1>

<p align="center">
  <b>Make vendor decisions from live evidence, not stale spreadsheets.</b><br>
  Real-time web research · Cited comparisons · Risk signals · Refresh history
</p>

---

VendorProof is an evidence-first AI procurement desk for small teams. Give it a
software or supplier brief and it checks pricing, capabilities, limits, and
recent risk signals through SerpApi. Every conclusion is tied to an exact source
URL, and Xano stores briefs plus evidence snapshots so a refresh can show what
changed.

The project is under active development for the SerpApi and Xano cash tracks of the
[DevNetwork API + Cloud + AI Hackathon 2026](https://api-cloud-ai-hackathon-2026.devpost.com/).

## Planned workflow

```text
Procurement brief
   |
   v
Verification checklist
   |
   v
Live SerpApi web + news search
   |
   v
Evidence-bounded comparison
   |
   v
Shortlist / review / hold decision
```
