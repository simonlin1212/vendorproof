# DevNetwork competition gates

Verified from the official Devpost overview and rules on 2026-08-29.

## Event

- Event: DevNetwork [API + Cloud + AI] Hackathon 2026.
- Online deadline: 2026-09-04 01:00 Asia/Singapore.
- Eligibility: age 18 or older; participants from any country are allowed,
  subject to the official standard exceptions. Hong Kong is not listed among
  the excluded territories.

## SerpApi sponsor track

- Build an innovative AI application using one or more SerpApi APIs.
- The application must use reliable, structured, real-time web data.
- It should solve a meaningful problem and show how live search improves the AI
  experience.
- Judging considers originality, technical execution, integration depth,
  usability, and impact.
- First place: USD 1,000 cash plus USD 1,000 SerpApi credits.
- Second place: USD 500 cash plus USD 500 SerpApi credits.

The project counts only the cash portion when discussing prize value.

## Xano sponsor track

- Rebuild a business application with AI and use Xano for meaningful business
  logic, APIs, workflows, authentication, integrations, or data modeling.
- First place: USD 1,000 cash plus USD 500 Xano credit.
- Second place: USD 500 cash plus USD 500 Xano credit.
- Submission requires a public repository or shared project, a 2–4 minute
  end-to-end demo, and a build story explaining the replaced software, AI tools,
  elapsed build time, and what AI plus Xano accelerated.
- The official event link offers one month of Xano Essential with a coupon. No
  checkout may be completed unless the final amount is verified as zero.

## General submission evidence

- Project name and clear problem/solution story.
- Working implementation using the sponsor API at runtime.
- Public source repository or an explicitly shared code link.
- Screenshots and an end-to-end demo video.
- Build progress, real-world concept, and feasibility are the published overall
  judging criteria.
